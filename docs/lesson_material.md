# Lesson material

SimImmuneResponse was made to be used in biology classes.
The lesson material is in Dutch.

Material       |Formats
---------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Lesson         |[doc](lesson_material/TeachSimImmuneResponse.doc), [odt](lesson_material/TeachSimImmuneResponse.odt), [pdf](lesson_material/TeachSimImmuneResponse.pdf)
Evaluation test|[doc](lesson_material/TeachTestSimImmuneResponse.doc), [odt](lesson_material/TeachTestSimImmuneResponse.odt), [pdf](lesson_material/TeachTestSimImmuneResponse.pdf)

The lesson material was written for the original 2008 version.
The current version works the same,
but the cells, buttons and panels are shown in one window
instead of in separate windows.
